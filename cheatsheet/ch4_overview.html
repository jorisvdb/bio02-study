Ch 4 · Tools and techniques – the 8 hangers (kapstokken)

Story: cells → copy → sort → read → find → gene on? → protein? → change · S size P pairing probe A antibody F fluorescence

1Material where? · 4.01–4.02

  • Model organisms E. coli · yeast · worm · fly · zebrafish · mouse · Arabidopsis
  • Culture liquid · agar plate → 1 cell = 1 colony = clone
  • Primary cells mortal ↔ cell line immortal
  • Stem cells ES (embryo) · iPS (adult cell reprogrammed) · blood (bone marrow)
  • totipotent = all (ES) · pluripotent = some
  • Virus only in living cells → plaque assay 1 virus = 1 hole → count

2Copy DNA make more · 4.03–4.05

  • PCR P 95° split → 55° primers → 72° build · ×30 · tube
  • RT mRNA → cDNA · reverse transcriptase (virus, ch 3)
  • Cloning cut (restriction enzyme) → glue (ligase) → plasmid → bacteria
  • Library many clones · genomic (all) · cDNA (active genes)
  • PCR fast, tube ↔ cloning slow, living cells

3Measure & sort how much? size? · 4.07–4.08

  • Absorbance DNA 260 nm · protein 280 nm · A260/A280 = purity · Beer–Lambert
  • Dye F ethidium bromide → DNA glows (UV)
  • Activity assay measure the product, not the enzyme
  • Agarose gel S DNA/RNA · − → + · small = fast
  • SDS-PAGE S proteins · SDS = unfold + all negative → size only
  • Mass spec weigh pieces → which protein

4Read the sequence letters · 4.09–4.11

  • Sanger SF ddNTP = stop → sort by size · ~900 letters
  • Shotgun random pieces → read → overlap · coverage 30×
  • Illumina F 2nd gen · short (150) · millions · 1 colour / cycle
  • Nanopore 3rd gen · long · strand through pore → current
  • WGS all · WES exons 1.5 % · targeted few, deep · epigenome · microbes
  • BLAST sequence vs database → which gene / species?

5Find a DNA sequence where? · 4.12

  • Restriction pattern S cut → gel → band pattern changes
  • Southern blot SP DNA gel → membrane → probe
  • Karyotype dividing cells → stain → count · 47,XX,+21
  • FISH PF glowing probe on chromosomes → where · how many
  • aCGH PF patient vs normal · 2 colours · chip → gain / loss
  • aCGH blind for balanced changes (inversion, translocation)

6Gene on? RNA · 4.13

  • Northern blot SP RNA gel → membrane → probe
  • qRT-PCR PF mRNA → cDNA → glowing PCR · early glow = much mRNA · 1 gene
  • Reporter F promoter + GFP / luciferase / lacZ → where · when
  • Microarray PF chip · 1000s of probes · 2 cell types
  • RNA-seq sequence all cDNA → count reads · all genes

7Protein there? proteins & cells · 4.12–4.13

  • Western blot SA SDS-PAGE → membrane → antibody → size · amount
  • ELISA A well + antibody → colour → how much (blood)
  • Immunofluorescence AF glowing antibody → microscope → where in cell
  • Flow cytometry AF cells 1 by 1 → laser → count · sort (FACS)
  • Mass spec → box 3

8Change the gene what happens? · 4.05–4.06

  • Forward mutant → gene · reverse gene → mutant
  • Mutagenesis random (chemicals, radiation) · site-directed (1 letter)
  • Transgenic + extra gene
  • RNAi / siRNA P destroy mRNA → knockdown · temporary · DNA intact
  • CRISPR-Cas9 P guide RNA → Cas9 cuts → broken / edited
  • Knockout mouse ES cells → chimera → breed → no gene
S Sorting by sizemolecules through a gel: small ones run fastest · gels, Sanger, every blot
P Pairing (probe)a short known piece sticks only to its matching strand (A–T, G–C) · PCR, FISH, arrays, blots, CRISPR
A Antibodya protein that grabs exactly one other protein · Western, ELISA, immunofluorescence, flow
F Fluorescencea label that glows in a colour when light shines on it · GFP, FISH, qRT-PCR, Illumina
The blot family: gel → membrane → findSouthern = DNA + probe · Northern = RNA + probe · Western = protein + antibody
