BIO02 – the steps · every process in order · ⚠ = exam trap

1 · Chromosomes

  1. homologs fail to separate
  2. both go to one daughter cell
  3. meiosis II copies the error
  4. 4 wrong gametes: 2 × n+1, 2 × n−1
  1. meiosis I normal
  2. sister chromatids stay together
  3. only one cell wrong
  4. 2 normal, 1 × n+1, 1 × n−1
  1. wrong gamete + normal gamete
  2. zygote 2n+1 (trisomy) or 2n−1 (monosomy)
  3. mitosis copies it to every cell
  4. wrong gene dose → miscarriage or syndrome

10–25 % of conceptions; main cause of pregnancy loss. Mitotic nondisjunction → mosaic.

  1. 3n: diploid egg + normal sperm
  2. 4n: zygote copies DNA, does not divide
  3. plants fine (banana 3n, wheat 6n, strawberry 8n)

One extra chromosome upsets balance more than a whole set.

  1. fragment lost → deletion
  2. fragment joins sister/homolog → duplication
  3. fragment flips → inversion
  4. fragment joins other chromosome → translocation

Unequal crossover = 1 deletion + 1 duplication. Inversion/reciprocal translocation keep all genes: position effect.

  1. Down 47,+21; risk ↑ with mother's age
  2. Klinefelter 47,XXY; Turner 45,X (only viable monosomy)
  3. cri du chat: deletion 5p
  4. CML: translocation 9;22 → Philadelphia, fused gene

2 · Cancer

Begin: a society of cells under social controls → goal of the cheat: divide without permission.

  1. 1 cell mutates, divides a bit more → clone
  2. more hits (Knudson), selection in the tumour
  3. benign: stays above the basal lamina
  4. malignant: breaks through, invades
  5. instability (chromothripsis) speeds it up
  6. subclones: heterogeneity
  7. stroma, angiogenesis, immune escape
  8. metastasis: vessel → travel → colonise

Carcinoma 85 % (epithelium); < 1/1000 cells survive the blood; colonisation is the hard step.

  1. own growth signals
  2. ignore stop signals
  3. escape apoptosis
  4. unlimited divisions (telomeres)
  5. angiogenesis
  6. invasion + metastasis
  1. point mutation → hyperactive protein
  2. amplification → too much protein
  3. rearrangement → fusion / strong promoter
  1. copy 1: deletion or point mutation
  2. copy 2: chromosome lost, mitotic recombination, gene conversion, deletion, mutation, or methylation
  3. hereditary Rb: hit 1 inherited → many tumours

Oncogene: same missense mutation repeats. Tumor suppressor: truncating mutations anywhere.

  1. stress: DNA damage, hypoxia, short telomeres, oncogene overdrive
  2. p53 stabilised, binds DNA
  3. p21 → blocks Cdk → no S phase
  4. or senescence, or apoptosis

p53 mutated in ≈ 50 % of cancers. Three pathways broken: Rb, Ras/PI3K, p53.

  1. Apc lost (early, polyp)
  2. instability
  3. K-Ras activated
  4. p53 lost → carcinoma

3 · Viruses

Begin: genes in a protein coat, no metabolism → goal: hundreds of copies, made by the host.

  1. surface protein ↔ host receptor (host range)
  2. genome enters (inject, endocytosis, fusion)
  3. host copies genome, makes proteins
  4. self-assembly
  5. exit: lysis or budding

DNA virus: host DNA polymerase. RNA virus: own RNA → RNA polymerase (cells lack it).

  1. spike binds receptor; envelope fuses
  2. ER ribosomes make glycoproteins
  3. ER + Golgi add sugars → membrane
  4. capsid buds out wrapped in membrane
  1. fuse; 2 RNA + 2 reverse transcriptase in
  2. RT: RNA → DNA (cytoplasm)
  3. DNA into nucleus, integrates = provirus
  4. host RNA pol → RNA = mRNA + genomes
  5. proteins, assembly, budding

Six classes: I dsDNA, II ssDNA, III dsRNA, IV +ssRNA (= mRNA), V −ssRNA (template), VI retro.

4 · Techniques

  1. denature 94–98 °C
  2. anneal primers 50–65 °C
  3. extend 72 °C (Taq, 5′→3′)
  4. repeat 20–40×: 20 → 10⁶ copies

Needs template, 2 primers, dNTPs, polymerase (no ligase).

  1. mRNA + reverse transcriptase → DNA
  2. RNA removed; polymerase makes strand 2
  3. no introns; then PCR
  1. cut insert + vector, same enzyme
  2. sticky ends pair
  3. ligase seals
  4. transform competent E. coli
  5. select on antibiotic

Ligase joins; restriction enzyme cuts (palindrome 4–8 bp).

  1. guide RNA leads Cas9 to the site
  2. double-strand break
  3. NHEJ: errors → knockout
  4. HR + template → precise edit
  1. dsRNA → Dicer → siRNA (21 nt)
  2. Argonaute keeps one strand
  3. pairs with mRNA → destroyed/blocked
  1. ES cells: gene → marker (HR)
  2. select in G418
  3. inject in black blastocyst
  4. chimeric pup; backcross; germline
  5. cross heterozygotes → knockout
  1. primer + polymerase + dNTPs + little ddNTP
  2. chain stops at ddNTP (no 3′ OH)
  3. ladder sorted by length
  4. read shortest first; colour = base
  1. fragment, linkers, PCR
  2. sequence all
  3. assemble by overlaps
  4. 8 genome equivalents → 99.9 %
  1. adapters; bridge PCR → clusters
  2. add 1 blocked fluorescent base
  3. photograph
  4. remove block + dye; repeat

Reads 75–150 bp. Nanopore: current through a pore, long reads, no PCR.

  1. fragments + biotin RNA probes (exons)
  2. streptavidin beads catch them
  3. wash 98.5 % away; sequence
  1. SDS-PAGE
  2. transfer to membrane
  3. block (BSA)
  4. primary antibody
  5. secondary antibody + label → band
  1. one gene's RNA → qRT-PCR
  2. all genes → microarray / RNA-seq
  3. place on chromosome → FISH
  4. copy number genome-wide → aCGH
  5. one protein → Western; cells → flow cytometry
